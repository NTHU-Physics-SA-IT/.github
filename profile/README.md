## **01 / WHO WE ARE**

我們是**清大物理系系學會資訊組**，負責開發、維護與改善面向物理系學生的數位工具、資訊平台與技術基礎設施。

**We design and maintain reliable digital systems for the NTHU Physics student community.**

```text
ACCESS          -> make information discoverable
RELIABILITY     -> keep student services available
MAINTAINABILITY -> make future handovers safer
DOCUMENTATION   -> preserve operational knowledge
COLLABORATION   -> build systems together
```

我們是 **Physics Student Association IT Team**，不是校方行政資訊單位或物理系官方 IT Office。

### **PHYSARCHIVE / NTHU PHYSICS PAST EXAM PLATFORM**

面向清大物理系學生的考古題與課程資料平台，提供**課程分類、條件搜尋、文件預覽、投稿、審核、討論、公告、通知與管理流程**。

**A student-focused archive platform for organizing, searching, previewing, submitting, reviewing, and discussing physics course materials.**

**[Repository](https://github.com/NTHU-Physics-SA-IT/PastExamWeb_PHY)** · **[Live Site](https://physarchive.com/)**

## **03 / WHAT WE BUILD**

```text
STUDENT PLATFORMS -> accessible archive and course-material workflows
KNOWLEDGE SYSTEMS -> searchable and structured academic resources
AUTOMATION        -> repeatable review, testing, and delivery checks
INFRASTRUCTURE    -> composable deployment, storage, and service layers
DOCUMENTATION     -> safer handover between future maintainers
```

這些方向以目前公開程式碼與維運文件為基礎；尚未啟用或仍在規劃中的能力，不會被描述為既有服務。

## **04 / ENGINEERING STACK**

```text
FRONTEND       Vue 3 / Vite / PrimeVue / Tailwind CSS
BACKEND        Python / FastAPI / SQLModel / Alembic
DATA           PostgreSQL / Redis / MinIO
INFRASTRUCTURE Docker Compose / Nginx / GitHub Actions
QUALITY        Vitest / Playwright / pytest / Ruff
```

技術清單來自公開 repository 的依賴、Compose 設定與 workflow；不公開憑證、環境變數、主機位址或私人維運資訊。
